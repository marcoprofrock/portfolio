## Architecture
### Intro Timeline
- Scroll-driven animation (500vh scroll container)
- Pixel-art Mac character (`#chatTrigger`) starts centered, moves right, shrinks to corner
- 3 stations (2021, 2023, 2024) fade in/out at scroll progress milestones
- After timeline ends (progress >= 0.97), Mac gets `.settled` class → becomes clickable chat trigger

### Mini Mac Walk System
- After settling, Mac idles for 5s then walks to opposite side of screen
- Walk animation: sit → stand → turn → side-walk → turn → sit
- 8 face expressions (happy, wink, surprised, bored, cheeky, sideEye, excited, dead)
- Speech bubbles with "click me" messages
- Clickable on both left and right side → opens Mac chat overlay
- `MutationObserver` watches for `.settled` class to activate/deactivate walk system

### Mac Chat Overlay
- Retro 1984 Macintosh UI with Q&A pool
- Free-text input forwards to Formspree (hello@marco.ad)
- Contact info shown after 2+ questions

### Photo Gallery
- Loaded from `index.json` manifest
- Fisher-Yates shuffle on load
- Horizontal scroll track with lightbox

### 500l/s Typeface Tester (live in `index.html`)
- Lives in the live `index.html` — a `<section class="tt">` panel inside the `#p-500ls` project block (collapsed `<details>`, so it shows when the project is expanded). Module CSS = `<style id="tt-style">` before `</head>`; logic = `<script id="tt-script">` before `</body>` (guards `if(!preview)return`). Relative asset paths (`assets/fonts/500ls/…`). The old standalone `/500ls/` page was removed after going live.
- Source of truth for the behaviour is `33_BA_500ls/12_BA_ABGABE_klein/07_Anhang_G_Headline_Extended_Script_randomizer.jsx` (the Illustrator randomizer), NOT just the thesis. Keep them in sync if cuts/colors change.
- 13 cuts = 13 Stuttgart springs, each with a fixed colour. Cut→HEX (from the script): 01 #EDEC3F · 02 #9DE89F · 03 #62C2B1 · 04 #FFC03F · 05 #FFAE3B · 06 #FFE552 · 07 #FCCF61 · 08 #D4E458 · 09 #0076AD · 10 #00ABC2 · 11 #3F526F · 12 #235BA8 · 13 #008DB1. Fonts are `@font-face` families `ls01…ls13` → `assets/fonts/500ls/500ls-NN.otf`.
- **Dachmarke (mix):** each glyph gets a random cut **+ that cut's colour as a pair**, never the same cut twice in a row. **Einzelschnitt:** one cut+colour for all glyphs (caption shows spring + HEX).
- **Baseline wave:** per-glyph `translateY(±wf · pct em)`, slider 0–100 % (= Illustrator `fontSize · pct`). **Defaults to 15 %** on load.
- **Weight (two glyph sets, NOT real case):** the font's "uppercase" and "lowercase" codepoints are two distinct glyph designs; the **lowercase-codepoint set is the heavier one** (measured fill ratio 0.806 vs 0.672). The `#ttCase` select (kept that id internally) is labelled **Weight** with options **As typed** (`none`) / **Light** (`upper` = finer set) / **Heavy** (`lower` = thicker set) / **Mixed** (`random`, per-glyph stable via `rolls[].uc`). Mixing both sets gives a more diverse texture — that's why default = **Mixed**.
- UI chrome is **English** (the spring names stay in German). Controls: text field, Cut select ("Mixed — all 13 cuts" = Dachmarke + the 13 springs under "Single cut (spring)"), Weight select (see above), Baseline wave slider, "↻ Shuffle". Mix caption: "13 cuts · randomly mixed · no cut twice in a row". On each page load the text field is seeded with a **random word from a mineral/ion `POOL`** (Calcium, Magnesium, Sodium, Potassium, Chloride, Sulfate, Bicarbonate, Carbonate, Fluoride, Lithium, Strontium — the constituents that occur in the springs; HTML fallback value "Calcium"). The old explanatory `.tt-sub` paragraph was removed (the case film already explains it; the `.tt-sub` CSS rule is now unused). Per-position randomness is stored in a `rolls[]` array so typing/sliding doesn't reshuffle existing glyphs; Shuffle regenerates it.
- Default load = mixed cuts + colour + Mixed weight + baseline wave 15 %. Tester window background = brandbook **Cloud Dancer** `#F0EEE9` (genuine PANTONE 11-4201 TCX off-white; brandbook prints it as #FFFFFF but pure white would vanish on the light theme) on BOTH dark/light themes.
- Ported into the live `index.html` by extracting the `tt-style` / `<section class="tt">` / `tt-script` blocks from the prototype and injecting them (before `</head>`, into `#p-500ls` between the `.info` close and `.cc-hint`, before `</body>`), rewriting `/assets`→`assets`.

### 500l/s Case Study (`/500ls/`)
- `500ls/index.html` is a **standalone case-study landing page** for the ADCE Student Award submission. Separate from the live tester in `index.html` (above) — it reuses the same `.tt` widget + 13 `@font-face` but exists as its own jury-facing page so the submission can link a short, distraction-free URL.
- Self-contained single-file HTML, **root-relative `/assets`** paths (it lives in a subfolder). Reuses the main design system's type/spacing/components (Inter preload, CSS vars, `.wrap` container) but is **light-only**: `:root` is the light palette with `--bg:#F0EEE9` (Cloud Dancer) + `--fg:#16160f`; the former dark vars, the `html.light` block, the theme-toggle button/CSS/JS and the anti-FOUC head script were all removed. Logos are black (`brightness(0)`); surfaces are faint-dark tints on the cream; the springs/awards cards stay white so they read against the cream page.
- The sticky header `.top` is full-width (translucent Cloud Dancer blur) but its inner content sits in a `.top-inner` capped at `--content-max` and centred — so the back-link/“Try the typeface ↓” line up flush-left with the hero + all section content (the `.wrap` gutter). NB: `.cs-hero` must set `padding-top`/`padding-bottom` (NOT the `padding` shorthand) so it doesn't clobber `.wrap`'s horizontal gutter.
- Sections top→bottom: minimal header (← back to `/` + "Try the typeface ↓", no toggle) → hero (colour logo + tagline H1 + Client/Year + **"Project: Bachelor thesis · solo"** + award badges) → "The idea" (Problem/Idea/Solution **verbatim from `#p-500ls`**, 3-col desktop) → case film (same lite-yt lazy YouTube `JCJF8uDo0tQ`, "press CC") → key-visuals gallery (`/assets/05_500ls/…`, lightbox) → "The parametric system" (specimen video + the `.tt` tester + a `.springs` 13-card legend) → credits + awards → footer (hello@marco.ad + ← back + Imprint/Privacy).
- **Credits/awards (don't undersell — it's a solo BA):** the credits list uses **Scope = "Bachelor thesis — concept, brand identity, type design & campaign, created entirely solo"** (no "Role/Art Direction"). Awards list (4): TDC Young Ones 2026 (Certificate of Typographic Excellence), **The World's Best Typography — selected for the TDC Annual 2026** (uses the TDC logo), ADC Young Ones 2026 (Merit), ADC Talent Award 2026 (1× Bronze). Same list mirrored in the JSON-LD `award[]`.
- **Case-film poster:** uses YouTube `sddefault.jpg` (+ `hqdefault` fallback), NOT `maxresdefault` — the case film is ~4:3, so the 16:9 maxres thumb has black pillarbox bars baked in; the 4:3 sd/hq thumb + `object-fit:cover` crops cleanly to the 16:9 frame with no bars.
- `.springs` legend: 13 cards on a Cloud-Dancer panel, each showing the spring's initial in its own cut font + colour, plus `Cut NN`, name, swatch + HEX. Built in `tt-script` from the same `CUTS` array (single source of truth).
- **Type-specimen video** (`.specimen`, between the section lead and the tester): `assets/05_500ls/500l_s_Showcase_1080x1920_60s_1.mp4` (1080×1920 9:16, 60 s, ~4.4 MB) embedded as an inline `<video autoplay muted loop playsinline>` — gif-style, no controls/play button. Kept native 9:16 (centered, phone-format, max-width `min(400px,78vw)`); NOT cropped (no glyphs lost, no re-encode). Own `<script>`: pauses when scrolled out of view (IntersectionObserver); on **fine-pointer** devices adds `.scrubbable` and **hover scrubs** — cursor Y maps linearly to `currentTime` (top=0, bottom=end), pausing playback while hovering and resuming the loop on mouse-leave, with a thin `.specimen-scrub` indicator line + a "· hover to scrub" caption hint (both gated on `.scrubbable`). Touch/coarse-pointer devices skip all that and just loop. NB: scrubbing needs HTTP **Range** support — fine on GitHub Pages; the local `python -m http.server` does NOT do ranges (video stays non-seekable in that preview).
- Tester default state is **pinned on load** (`mix` / `random` weight / `15%` wave) in `tt-script` so browser form-state restoration can't drift the controls (HTML attrs already say so; JS enforces it). This pin is specific to the case-study page's tt-script.
- **SEO/Analytics (Marco's decisions):** `noindex,nofollow` + self-canonical + robots.txt Disallow `/500ls/` + NOT in sitemap (avoids duplicate content with `#p-500ls`). GA4 (`G-9G9TJLTWJ8`) loads **directly in `<head>` with NO cookie banner** (deliberate for this submission page) and fires a custom `gtag('event','adce_case_view',{project:'500ls',source:'adce_student_award'})` on load so jury visits are a distinct event; lite-yt clicks fire `video_play`.
- Hand-authored artefact (not generated from `index.html`); edit it directly. `index.html` is untouched by this page.
